Syntax & limits

Literals, parentheses, concatenation, alternation |, postfix * + ?, character classes [a-z] and negated classes [^a-z] are supported. Dot matches any Unicode code point, including newline. Escape punctuation for literal operators; \n, \r and \t represent controls. Empty patterns, groups and alternatives match the empty string.

No captures, backreferences, lookarounds, anchors, counted repetition, shorthand classes, flags, lazy quantifiers or substring search. Unsupported syntax is rejected. Patterns are limited to 256 code points, group depth 32, automata to 1024 states and inspected input to 2000 code points. Unicode normalization and grapheme segmentation are not performed.

Edge checks count closure edge inspections plus consuming-edge predicate tests; they are not CPU timing or every internal operation. Matching uses state sets with O(pattern size × input length) work. Retaining the inspection trace also uses O(states × input length) space. This is an educational engine, not a replacement for a maintained production regex library.
